# Website Resmi Nasi Kulit Mak Igun (Cabang Surabaya Pusat)

Website resmi untuk warung kuliner **Nasi Kulit Mak Igun**, hasil kolaborasi antara desainer **Ivan Gunawan** dan MasterChef Indonesia **King Abdi**.

---

## 🎨 Identitas Visual & Desain
Website ini didesain mengacu pada referensi identitas resmi Instagram [@nasikulitmakigun.surabayapusat](https://www.instagram.com/nasikulitmakigun.surabayapusat/?hl=en) dan logo original:

- **Warna Utama:** 
  - Vibrant Warm Orange (`#FF6700`)
  - Deep Royal Purple (`#5A1679`)
  - Accent Sunshine Yellow (`#FFC400`)
  - Warm Off-White / Cream (`#FFF9F2`)
- **Tipografi:** 
  - Font Judul Display: `Titan One` & `Fredoka` (bergaya pop-art kuliner playful, ceria, dan menggugah selera).
  - Font Konten / Body: `Plus Jakarta Sans` (modern, rapi, dan mudah dibaca di mobile/desktop).

## 🚀 Cara Menjalankan Website

### Opsi 1: Buka Langsung (Tanpa Server / Offline)
Cukup klik ganda (double-click) file `index.html` pada File Explorer:
```text
C:\Users\Abie\nasikulit-makigun-website\index.html
```
*(Seluruh perubahan data admin akan tersimpan otomatis di `localStorage` peramban).*

### Opsi 2: Jalankan via Local Web Server (Node.js) - Disarankan
Buka terminal / PowerShell di folder proyek ini:
```powershell
cd C:\Users\Abie\nasikulit-makigun-website
node server.js
```
Lalu buka browser di:
```text
http://localhost:3000
```
*(Data yang disimpan di admin akan otomatis tersinkronisasi ke file `data.json` di server sekaligus `localStorage` browser).*

## 👑 Panel Pengelola & Admin (Lengkap 7 Tab)

Website telah dilengkapi dengan sistem **Panel Admin Lengkap** yang memungkinkan pengelolaan seluruh isi website tanpa perlu coding:

### 🔐 Cara Masuk ke Panel Admin
Panel admin sengaja dibuat **terpisah dan tersembunyi** dari antarmuka halaman pengunjung (`index.html`) agar aman dan profesional.
Untuk mengakses panel pengelola:
1. Buka URL: **`http://localhost:3000/admin`** atau **`http://localhost:3000/admin.html`** (jika menjalankan server).
   *Atau langsung buka file `admin.html` pada browser Anda jika secara offline.*
2. Masukkan akun admin bawaan:
   - **Username:** `admin`
   - **Password:** `makigun123`
   *(Password dapat diganti kapan saja di dalam tab Akun & Cadangan)*.

### 📋 Fitur-Fitur 7 Tab Panel Admin

#### 1. 📋 Kelola Menu
- **Tambah & Edit Menu:** Nama, Kategori, Harga (Rp), Tag Promo/Badge (misal: *Wajib Coba*, *Best Seller*, *Pedas Gurih*), Deskripsi, dan Foto Menu.
- **Upload Gambar:** Bisa menggunakan path file lokal (`images/menu/...`), URL eksternal, atau **upload langsung file foto dari laptop/komputer**.
- **Ketersediaan Menu:** Saklar instan **Tersedia** atau **Habis**. Jika diubah menjadi habis, kartu menu di website otomatis diberi label *HABIS* dan tombol pesan dinonaktifkan.
- **Hapus Menu & Cari Menu:** Filter dan cari menu di tabel admin dengan mudah.

#### 2. 🖼️ Edit Cover (Hero Section)
- **Visual Branding:** Ganti logo utama (path atau upload gambar).
- **Badge Viral:** Ubah teks badge 1 (*100% Halal*) dan badge 2 (*Kolaborasi Ivan Gunawan & King Abdi*).
- **Headline & Tagline:** Edit judul besar baris 1 & 2 serta deskripsi tagline utama.
- **3 Kartu Keunggulan (Highlights):** Ubah ikon, judul, dan teks keterangan untuk 3 kartu keunggulan di cover.
- **3 Tombol Aksi (CTA):** Ubah teks dan tujuan tautan tombol *Lihat Menu*, *Order WhatsApp*, dan *Alamat Outlet*.
- **4 Stiker Floating:** Ubah teks 4 stiker melayang bertema pop-art kuliner.

#### 3. 📸 Kelola Galeri (Instagram & Warung)
- **Tabel Foto Galeri:** Lihat daftar foto yang aktif ditampilkan di website.
- **Tambah / Edit Foto Galeri:** Masukkan judul foto, kategori (Makanan, Suasana, Sambal, Minuman), tagar Instagram (misal `#makigun #kulitsurabaya`), keterangan foto, dan foto (URL/path atau upload dari laptop).
- **Hapus Foto:** Hapus foto galeri lama yang sudah tidak ingin ditampilkan.
- **Integrasi Lightbox:** Foto yang ditambahkan otomatis mendukung popup zoom resolusi penuh saat diklik pengunjung.

#### 4. 📍 Alamat & Lokasi
- **Identitas Cabang:** Nama cabang dan alamat lengkap.
- **Jam Operasional & Status Live:** Teks jam buka dan penentuan jam buka/tutup format 24 jam (misal 10 s/d 24 WIB) yang mengontrol status *BUKA SEKARANG / TUTUP* secara live.
- **Fasilitas & Pembayaran:** Keterangan fasilitas cabang (AC, Dine-in, Parkir) dan metode pembayaran yang diterima (Cash, QRIS, Transfer).
- **Peta Google Maps:** Ubah tautan buka rute Google Maps dan kode iframe Embed peta interaktif.
- **Info Cabang Lain:** Keterangan ketersediaan cabang lain di Surabaya.

#### 5. 📱 Kontak & Medsos
- **Bilah Pengumuman (Top Bar):** Ubah teks pengumuman berjalan di bagian paling atas website.
- **WhatsApp Hotline:** Nomor WhatsApp format internasional (`628...`) dan format tampilan (`0877-7772-8228`).
- **Instagram:** Akun & link profil Instagram cabang Surabaya Pusat serta Instagram resmi Mak Igun Pusat.
- **Mitra Pesan Online (Delivery):** Tautan pemesanan online untuk GoFood, GrabFood, dan ShopeeFood.
- **Hotline Kemitraan:** Nomor / tautan informasi kemitraan franchise Mak Igun.

#### 6. 🎁 Promo Spesial (Pop-up & Voucher)
- **Saklar Status Promo:** Aktifkan / nonaktifkan seluruh tampilan promo & kupon di website.
- **Saklar Auto Pop-up:** Mengatur apakah modal promo muncul otomatis di awal sesi kunjungan.
- **Pita Banner Atas (Strip Banner):** Pita promosi gradien bergerak di bawah header dengan kode voucher dan tombol klaim.
- **Tombol Floating Promo:** Tombol mengambang dengan efek denyut halus (*pulsing ripple*) di pojok bawah layar.
- **Modal Pop-up Interaktif:** Banner gambar promo, diskon badge melayang, judul promo, deskripsi, masa berlaku, syarat minimal belanja, serta kotak kode kupon dengan tombol **"Salin Kode" (One-Click Copy)**.
- **Integrasi Keranjang & WhatsApp:** Kolom input voucher di keranjang pesanan, perhitungan diskon otomatis, dan detail kode voucher + potongan harga tertera rapi pada format pesan WhatsApp!

#### 7. ⚙️ Akun & Cadangan
- **Ganti Password Admin:** Perbarui password login demi keamanan.
- **Unduh Cadangan JSON (Backup):** Mengunduh seluruh data (Menu, Cover, Galeri, Lokasi, Kontak, Promo, Pengaturan) ke dalam 1 file `makigun-data-backup-*.json`.
- **Pulihkan Data JSON (Restore):** Memulihkan data website secara menyeluruh dari file JSON cadangan.
- **Reset ke Data Pabrik:** Mengembalikan seluruh menu, galeri, cover, lokasi, kontak, dan promo ke setelan default awal Mak Igun kapan pun dibutuhkan.
